# Сайт-визитка: Андрей Шальнов

Одностраничный сайт-визитка (Product & Engineering Director · электроника 0→1 до серии).

**Публикация:** GitHub Pages — https://andreyshalnov.github.io/iam/

## Структура

| Файл | Назначение |
|------|-----------|
| `index.html` | Весь сайт: разметка, стили и контент в одном файле (без внешних зависимостей) |
| `.nojekyll` | Отключает обработку Jekyll в GitHub Pages |

## Как обновить сайт

1. Открыть `index.html`, внести правки (текст — прямо в разметке, стили — в блоке `<style>`).
2. Закоммитить и запушить в `main`:

```bash
git add index.html
git commit -m "Обновление визитки"
git push origin main
```

3. GitHub Pages обновит страницу в течение 1–2 минут.

## Технические детали

- Один HTML-файл: нет JS-фреймворков, нет внешних шрифтов и CDN — страница загружается мгновенно и не зависит от сторонних сервисов.
- Адаптивная вёрстка (десктоп / планшет / телефон) + корректная печать (Ctrl+P).
- Мета-теги, Open Graph и JSON-LD (schema.org/Person) для поисковиков и превью в мессенджерах.
- Favicon — inline SVG с монограммой, без отдельных файлов.
